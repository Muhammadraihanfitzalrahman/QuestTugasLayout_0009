# QuestTugasLayout_0009 - Tugas 3 Jetpack Compose

Proyek Android menggunakan Jetpack Compose untuk menampilkan data Kartu Mahasiswa (Card Widget).

### 📋 Aturan Praktikum:
1. **Resources**: Seluruh Warna (`colors.xml`), Gambar (`res/drawable/logo_umy.png`), dan Kata (`strings.xml`) disajikan melalui Android Resources.
2. **Reusable Card Widget**: Komponen Card dibuat dalam 1 fungsi terpisah `@Composable fun CardWidget(...)` yang digunakan oleh seluruh Card.
3. **No Hardcode**: Tanpa hardcode string, warna, maupun drawable pada fungsi UI composable.
4. **Jetpack Compose**: Menggunakan Layout Jetpack Compose (`Column`, `Row`, `Card`, `Text`, `Image`).
